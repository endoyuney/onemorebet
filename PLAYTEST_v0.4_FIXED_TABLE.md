# ONE MORE BET v0.4 — Fixed Table playtest

This iteration tests the new permanent-table architecture before Scratch is rebuilt.

## Core changes
- Full-screen felt table; shop, prestige, upgrades and legacy Scratch/Slot controls live in a fixed side rail.
- Copper is now 50/50: heads +$5, tails -$3.
- Silver: 42% win, +$30 / -$15.
- Gold: 34% win, +$160 / -$75.
- Coin purchases remain physical objects on the table, max 50.
- Manual hand progression is 1 → 5 → 15 → 25 → 35 → 50 mixed coins.
- No separate early FLIP ALL. The final hand rank is the 50-coin equivalent.
- Every flip throws the selected coins to new random positions on the table.
- Manual prestige is available through SMASH TABLE once the current table score reaches a chip threshold.
- A real BUST pays one extra danger chip compared with a safe manual smash at the same score.
- Table score uses peak cash plus 55% of run investment; this rewards building the table instead of hoarding cash only.

## Questions
1. Does Copper now give enough breathing room before the first prestige?
2. Is the first 1 → 5 hand upgrade a meaningful reason to prestige?
3. After unlocking hand 5, do you want to own 5 coins?
4. Does mixing Copper/Silver/Gold under one hand button feel natural?
5. Does SMASH TABLE feel like a satisfying voluntary prestige rather than a quit button?
6. Is the +1 chip BUST bonus enough to tempt extra risk without making manual prestige feel wrong?
7. Do coins jumping to new positions create useful visual chaos, or just visual noise?
8. Is the table large and stable enough that Scratch can be rebuilt directly on top of it in v0.5?

Do not tune Scratch yet. v0.5 will replace the legacy Scratch panel with physical tickets on the fixed table.
